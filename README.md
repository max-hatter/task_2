# Dependency Graph Tool (Вариант 27)

Инструмент визуализации графа зависимостей для менеджера пакетов.

## Запуск

python -m src.main -p <пакет> -r <url_или_файл> -m <режим> -v <версия> [параметры]

### Параметры:
* -p, --package — имя пакета
* -r, --repo — URL или путь к файлу
* -m, --mode — режим: url или file
* -v, --version — версия пакета
* -o, --output — имя файла графа (по умолчанию graph.png, только .png)
* -a, --ascii — вывод в виде ASCII-дерева

## Тесты

pytest tests/ -v
