# Инструмент визуализации графа зависимостей (Вариант 27)

Консольное приложение на Python для анализа и визуализации графа зависимостей пакетов менеджера **.NET (NuGet)**. 
В рамках выполнения задания **запрещено** использовать сторонние менеджеры пакетов (например, `dotnet`, `nuget`) для получения данных. Программа напрямую обращается к NuGet API и парсит XML-файлы конфигурации (`.nuspec`).

## Возможности (по этапам)

*   **Этап 1. Конфигурация:** Прием параметров через командную строку (CLI), их валидация и вывод в формате «ключ: значение».
*   **Этап 2. Сбор данных:** Прямое скачивание `.nuspec` файла из NuGet API (или чтение локального файла) и извлечение прямых зависимостей.
*   **Этап 3. Основные операции:** Построение графа зависимостей с помощью алгоритма **DFS (обход в глубину) с рекурсией**. Обработка циклических зависимостей. Поддержка тестового режима (чтение вымышленного графа из файла).
*   **Этап 4. Дополнительные операции:** Определение порядка загрузки зависимостей (топологическая сортировка).
*   **Этап 5. Визуализация:** Генерация текстового описания графа на языке **Mermaid**, сохранение изображения в формате **PNG**, а также вывод дерева зависимостей в формате **ASCII**.
